# Mini Online Judge

## Goal

Build a LeetCode-like Online Judge to learn:

* Backend Engineering
* System Design
* Job Queues
* Code Execution
* Deployment
* Docker
* Infrastructure Concepts

---

## Tech Stack

### Frontend

* React (Vite)
* React Router
* Axios
* Monaco Editor

### Backend

* Node.js
* Express
* MongoDB (Mongoose)

### Authentication

* Google OAuth

### Planned Infrastructure

* BullMQ ✅ implemented
* Redis  ✅ implemented
* Docker ✅ implemented (gcc:13 image)

---

## User Roles

### USER

* Browse problems
* Open problem page
* Write code
* Run code
* Submit code
* View submission history

### ADMIN

* Create questions
* Edit questions
* Delete questions
* Manage test cases

---

## Planned Collections (basic version - already modified)

### User

* googleId
* name
* email
* avatar
* role

### Question

* title (HTML via Quill)
* statement (HTML via Quill)
* difficulty
* topic (HTML via Quill)
* constraints (HTML via Quill)
* examples (embedded, shown to users)
* languages (codeSnippet + classSnippet per lang)
* officialSolution (admin-only, used for testcase output generation)
* comparatorType (EXACT_MATCH | FLOAT_EPSILON | CUSTOM)
* timeLimit
* memoryLimit
* questionNo (auto-incremented)

### TestCase

* questionId
* input
* output (auto-generated by tcGenWorker via officialSolution)

### Submission

* userId
* questionId
* code
* language
* status
* verdict
* executionTime
* memoryUsed
* compilerOutput
